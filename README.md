## 作品一覧

### おとして!串だんご

- **ジャンル**: パズル
- **制作期間**: 4ヶ月
- **開発環境**: Unity
- **チーム人数**: 4人
- **概要**:
  - 団子の落下箇所を移動させ、フィルターに通すことで色を変えて三色団子を作るゲーム。
  - 初めて制作したゲームであり、展示会に二度参加し、ブラッシュアップを重ねGC甲子園に出場。
- **担当箇所**:
  - アウトゲームの設計・実装を担当。
- **スクリプトの概要**:
    - `DangoRain.cs`
        - 結果発表のシーンにて、スコアに応じて団子が画面上部から降る演出を実装。
- **プレイ方法**
  - 以下のリンクからプレイできます  
    [おとして!串だんご](https://unityroom.com/games/otoshite_kushidango)

### リバースオフレコード

- **ジャンル**: パズル
- **制作期間**: 6ヶ月
- **開発環境**: Unity
- **チーム人数**: 7人
- **概要**:
  - リバーシのルールに則りつつ、「ヒミツマス」を追加し、裏返すことで相手のヒミツを暴けるゲーム。
  - 普段より多い人数でのチーム制作を経験し、プログラマとして最適なコミュニケーションを学ぶ。福岡ゲームコンテストに出場。
- **担当箇所**:
  - **プログラマ**: データ管理、オーディオの設計  
  - **デザイナー**: UIデザイン  
  - **プランナー**: レベル設計  
- **スクリプトの概要**:
    - `StageManager.cs`
        - ステージのクリア状況を保存。他のプログラマが参照しやすい設計を意識。
- **プレイ方法**
  - 以下のリンクからプレイできます  
    [リバースオフレコード](https://unityroom.com/games/reverse_off_the_record)

### 北山or比山

- **ジャンル**: アクション
- **制作期間**: 2ヶ月
- **開発環境**: Unity
- **チーム人数**: 2人
- **概要**:
  - Unity1週間ゲームジャム「かえす」に参加するために制作。
  - 展示会に二度参加し、ブラッシュアップを重ね、GC甲子園大賞ノミネート作品として選出。
- **担当箇所**:
  - プログラマ1名のため、コーディング全般を担当。
- **スクリプトの概要**:
    - `StampSpawner.cs`
        - 正解とダミーを混ぜたハンコ生成順を決定し、ハンコを生成。
    - `StampChecker.cs`
        - ハンコの正誤判定を実装。
- **プレイ方法**
  - 以下のリンクからプレイできます  
    [北山or比山](https://unityroom.com/games/kitayamaorhiyama)
